# Getting started

Two pages, for the two ways people arrive here.

- **[Installation](installation.md)** — you are building a front end and want the
  engine's commands inside your own application.
- **[Testing](testing.md)** — you are writing code against the engine and want to
  drive it without a cluster.

If you only want to *use* it, you want the [quickstart](../quickstart.md)
instead: the `cbox` binary already has all of this inside it.
